# Funzi Home Academy — homeschooling and curriculum pathways

## What is implemented

The **Homeschool** navigation section supports Kenyan-context planning across the discovery catalogue of Kenya CBE/CBC, legacy 8-4-4 revision, Cambridge International, Pearson Edexcel, International Baccalaureate, US Common Core, US NGSS, US AP, China national curriculum, England national curriculum, and Montessori- or Waldorf-inspired learning approaches. The last two are teaching approaches, not examination boards. **Catalog listings do not include licensed syllabi or imply authorization by any board.**

The Home Academy interface includes five sections:

1. **Plan & timetable:** choose a named pathway, stage, subjects, language, weekly hours, lesson length, blended/reading/visual/audio/practical learning style, Kenya-specific examples, low-bandwidth study preference, and a family goal. Produces an exactly time-budgeted Monday–Friday micro-schedule with breaks and CSV export.
2. **Learning log:** record subject, activity, date, minutes, reflection and non-sensitive evidence description. Each entry is labeled a learner self-report; monthly or weekly academic certification is **not** asserted. CSV export is an unverified record.
3. **Projects & AI:** reviewed, structured safe activity prompts for Kenyan numeracy, everyday science, ecology, language, civic contexts, computing and beginner Mandarin, plus fallback community inquiry projects. AI project guidance uses Funzi's existing moderated tutor and asks guiding questions, not graded or claimed standard-aligned answers.
4. **Curriculum bridge:** approximate *subject-name overlap only* between two pathways; shows broad shared areas and subjects worth investigating. This does **not** map grade outcomes, equivalences, credit, examination eligibility, or school-transfer rights. Families should seek official guidance and qualified educators.
5. **Guardian review:** family accounts can establish an access link via a 15-minute single-use code generated by a separate email-verified account; a logged-in learner must explicitly redeem it. Either side can revoke. A linked guardian can read reported study records, acknowledge entries, and request clarification. A guardian acknowledgement is **not** an independently graded assessment.

## Firebase Functions API

All callables enforce Firebase App Check and require authenticated users:

| Callable | Authorization | Purpose |
| --- | --- | --- |
| `saveHomeLearningPlan` | Signed-in user | Save user's bounded homeschool plan |
| `getMyHomeLearningDashboard` | Signed-in user | Fetch user's plan and latest 100 self-reported sessions |
| `recordHomeLearningSession` | Signed-in user | Save bounded study session tied to saved subjects |
| `createHomeGuardianInvite` | Email-verified signed-in attesting adult | Produce short-lived private code |
| `acceptHomeGuardianInvite` | Separate signed-in learner | Use code once; record linked account |
| `listMyHomeGuardianLinks` | Signed-in user | List accounts directly linked to that user |
| `revokeHomeGuardianLink` | Either link participant | Remove access immediately |
| `getHomeLearningFamilyDashboard` | Explicitly linked guardian | Fetch only this learner's permitted home-learning records |
| `reviewHomeLearningSession` | Explicitly linked guardian, not learner | Acknowledge or ask for correction |

The server stores `homeschoolProfiles/{uid}`, per-user `sessions`, and separate server-only `homeschoolGuardianInvites` and `homeschoolGuardianLinks`. Browser Firestore read/write access to these collections is denied. No raw sensitive student record is published to other schools or the tutoring marketplace. Rate limits, field lengths, one-time invitation use and server-side link checks constrain abuse. Study logs are limited to the latest 100 records per dashboard query; this is **not** a comprehensive school record export.

**Family consent caveat:** A parent invitation verifies account control and learner acceptance, but it does not establish legal custody, biological relationship, government ID, guardian age or consent law compliance. Before production with minors, implement age-appropriate parental authorization procedures, independently verify guardians where required, set retention and deletion policies, conduct child-safety and data-protection assessments, and establish human review and incident response.

## Deployment and validation

Deploy new Functions exports and Firestore rules from this PR to the correct Funzi Firebase project, configure Firebase Auth and App Check, then deploy the Vite web client. Never ship this as a pre-deployment 'live' feature. Run web build, Functions TypeScript build, `npm test`, and the Firestore emulator `npm run test:rules`.

The following require additional implementation and permissions before being advertised as active: licensed official syllabus ingestion, competency-to-standard maps, validated assessment banks and proctoring, certified transcripts, curriculum equivalency/recognition, offline PWA cache and synchronization, Mandarin speech scoring, actual AI personalization by curriculum, safeguarding/guardian verification, accessible media delivery, payments, and accredited school examinations.

## Operational safeguard

Keep learner-controlled study logs and guardian reviews **separate** from KNEC marks, school gradebooks, or international examination results. Linked schools may provide authorized coursework via the existing individual Workspace integration; Funzi does not overwrite the school's authoritative academic record. Teachers and guardians should manually verify project suitability and factual correctness of AI-generated explanations.
