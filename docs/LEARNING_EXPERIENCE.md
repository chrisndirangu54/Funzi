# Curriculum-aware learning experience

Funzi's engagement layer is evidence-driven. XP is awarded for validated learning events, not taps or time-on-screen.

## Gamification
Quests attach to curriculum skill IDs. XP sources include diagnostic completion, retrieval practice, quiz improvement, spaced-repetition reviews, projects and verified mastery gains. Streak protection should encourage recovery rather than punish absence. Improvement leagues remain separate from raw-mark rankings.

## Interactive mastery graph
Nodes represent curriculum concepts/skills; edges represent prerequisite and containment relationships. Node size/labels may expose evidence confidence, while mastery state controls progress presentation. Clicking a node opens evidence, prerequisite gaps, recommended resources and next actions.

## Infographics
Generate learner-safe visual summaries from structured mastery data: weekly learning recap, subject strengths/gaps, revision priorities, exam readiness and teacher/parent reports. Never infer sensitive traits.

## YouTube tagging
Store only video IDs, approved metadata, timestamps and curriculum tags. Do not download/rehost videos. Videos remain pending until educator review. Tags include skill IDs, grade range, language, difficulty, content type and useful timestamp segments. Prefer privacy-enhanced embeds and respect YouTube API/embedding terms.

## Procedural multimodal content
A curriculum-grounded generation job can request: diagram/picture brief, illustrated story, worked-example storyboard, mnemonic scene, comic sequence, role-play, simulation scenario or infographic specification. Generated content must carry curriculum IDs, generation provenance, age band, safety status and review status. It must never be labeled official KICD content.

## Further recommended systems
- Mastery quests that branch based on diagnostic evidence.
- Collaborative classroom quests with no public exposure of weak learners.
- Knowledge-map exploration and unlockable curriculum regions.
- Project portfolios and competency evidence, especially for CBE.
- Student-created explanations that the tutor critiques with a rubric.
- Simulation labs for science, geography and mathematics.
- Local-context story generator with language/difficulty controls.
- Accessibility modes: TTS, captions, dyslexia-friendly reading controls and low-bandwidth media alternatives.
- Teacher authoring studio for approving AI-generated activities and media mappings.
- Learning analytics that compare engagement with actual mastery gain so ineffective gamification can be retired.
